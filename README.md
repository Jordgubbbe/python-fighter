# 🥊 Python Fighter

Браузерная мультиплеерная игра в стиле ретро-файтингов (Tekken), где вместо ударов нужно отвечать на теоретические вопросы по языку Python.

## 🔗 Ссылка на игру
👉 **[Играть здесь](ССЫЛКА_НА_ТВОЮ_ИГРУ)**

*(Внимание: проект размещен на бесплатном тарифе Render, поэтому при первом заходе сервер может "просыпаться" около 30-50 секунд).*

## 🎮 Как играть
1. Открой игру по ссылке.
2. Введи свой никнейм.
3. Нажми **«Создать комнату»** и скопируй 6-значный код.
4. Отправь код другу (или открой игру во второй вкладке / в режиме инкогнито).
5. Введи код во втором окне и нажми **«Войти»**.
6. Отвечай на вопросы по Python быстрее соперника! Кто отвечает неправильно или не успевает — теряет HP. 

## 🛠 Технологии
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (без фреймворков).
* **Backend:** Node.js, Express.
* **Сеть:** Socket.io (WebSocket для синхронизации игры в реальном времени).
* **Деплой:** Render.
* **Хранение данных:** JSON-файл с вопросами (легко масштабируется).

## 📁 Структура проекта
* `client/` — клиентская часть (интерфейс, стили, логика отображения).
* `server/` — серверная часть (Node.js).
  * `index.js` — игровая логика, обработка Socket.io, комнаты.
  * `questions.json` — база вопросов.
